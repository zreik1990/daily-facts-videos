# Daily Facts Videos

Three animated cartoon videos a day (education 09:00, health 15:00, fun 20:00, Riyadh time),
posted to YouTube Shorts, Instagram Reels and TikTok through Metricool.

A scheduled Claude task runs this repo every night; see [RUNBOOK.md](RUNBOOK.md).
Videos are stored as release assets (one release per day). Scripts live in `FactScripts/`.
